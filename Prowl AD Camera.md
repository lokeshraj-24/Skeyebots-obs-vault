The communication protocol is built to accept and output three different communication frame
formats:
■ Command - to query the system
■ Response - reply received from the system in response to a query
■ Stream - to stream data from sub-devices

- These frame formats are same across all hardware protocols - Ethernet TCP, ethernet UDP and serial communication
